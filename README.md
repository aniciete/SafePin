# SafePin - Creating Safer Communities

SafePin is a community-driven safety platform that empowers citizens to anonymously report incidents and stay informed about safety concerns in their community. The platform bridges the gap between citizens and authorities, enabling effective communication while maintaining privacy and anonymity.

## Features

- 🔒 **Anonymous Reporting**: Submit incident reports without revealing your identity
- 📍 **Location-Based Alerts**: Stay informed about safety concerns in your area
- 🔍 **Report Verification**: All reports are verified by our dedicated team
- 👥 **Authority Integration**: Direct communication with law enforcement and emergency services
- 📱 **Mobile Responsive**: Access SafePin from any device
- 🗺️ **Interactive Map**: Visualize incident reports and safety information
- 📊 **Real-time Statistics**: Track community safety metrics
- 🔔 **Alert System**: Receive notifications about important safety updates

## Tech Stack

- **Frontend**: React, Vite, TailwindCSS
- **UI Components**: Custom components with modern design
- **Routing**: React Router for seamless navigation
- **Icons**: Font Awesome for consistent iconography
- **Styling**: TailwindCSS for utility-first styling
- **Code Quality**: ESLint, Prettier for code consistency
- **Build Tool**: Vite for fast development and optimized builds

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/safepin.git
   cd safepin
   ```

2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

3. Start the development server:
   ```bash
   npm run dev
   # or
   yarn dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

### Build for Production

```bash
npm run build
# or
yarn build
```

The build artifacts will be stored in the `dist/` directory.
